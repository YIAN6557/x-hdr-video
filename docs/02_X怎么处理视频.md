# X 怎么处理视频

所有数据都是 2026-10-31 从 X 实际下发的文件里查的：用公开的 [fxtwitter](https://github.com/FixTweet/FxTwitter) 接口（`https://api.fxtwitter.com/status/<帖子ID>`）拿到每个清晰度的 mp4，再用 ffprobe 读色彩标记、读码流里的编码器信息。`tools/check_x_video.sh` 就是把这个过程写成了一条命令。

## X 会把每个视频都重新压一遍

每个文件的码流里都有编码器留下的参数，所有账号都一样：

| 清晰度 | 编码器 | 质量 | 码率上限 |
|---|---|---|---|
| 1080p | libx264（Lavc62.28.102） | CRF 23 | 约 10 Mbps |
| 720p | libx264 | CRF 28 | 约 2 Mbps |

一般还会再出 270p 和 360p。没有哪个文件是原样转发的，所以 X 发出去的色彩标记，完全由 X 的转码程序决定。

## 三种结果

| X 下发的标记 | 意思 | 在手机上 |
|---|---|---|
| `arib-std-b67` / `bt2020` | **保留了 HLG** | 按 HDR 播放，会发光 |
| `bt709` / `bt709` | X 读到了 HDR，**转成了普通视频** | 颜色正常，不发光 |
| 没有标记（ffprobe 显示 `unknown`） | X **没读**文件里的色彩信息 | 把 HLG 信号当普通视频播，颜色发灰发淡 |

注意：普通视频本来就没有标记的话，X 发出去也是"没有标记"，这是正常的。只有上传的文件带了 HLG 标记、X 却发回"没有标记"，才说明 X 丢掉了它。

## 从表里能看出什么

**1. 格式决定"保留"还是"转成普通视频"。**
@naundob 第 3 次和第 4 次的视频都是 8.27 秒、30 帧；第 1、2 次和第 5 次都是 59.38 秒、60 帧。时长和帧率完全一样，很可能是同一段素材，只换了格式就从 bt709 变成了 HLG。@banbudev 也明确说第 2 条是"同一段 AI 视频换成 H.264 + HLG 编码"。所以在能用的账号上：

- H.264 8 位 HLG → 保留
- 杜比视界、HDR10、iPhone 原生 HDR → 转成普通视频
- HEVC → 转成普通视频（@banbudev 的经验）

**2. 账号决定"会不会读"。**
能用的账号，换格式会得到 bt709 或 HLG，说明 X 每次都读了色彩信息；不能用的账号，不管传什么，都是"没有标记"。两组账号失败的方式不一样，这是最关键的区别。

**3. 同一个文件，换个账号就不行。**
@xiayitiaoAI [说](https://x.com/xiayitiaoAI/status/2116411841375277511)，他把原博主在 X 上的视频下载下来（文件里有 HDR），原样重新上传，到他的号上就变成了普通视频。这是他自己的描述，我们没有复现。

**4. 不是运气，也不是时间。**
- 在能用的账号上，结果是固定的：@banbudev 换格式后 8/8，@hi_personality 9/9。
- 在不能用的账号上，结果也是固定的。
- 成功和失败在时间上是交错的：10-31 04:20–04:41 @danielbeanpole 连发 3 条都失败，而 @banbudev 在 04:05 和 05:07 发的都成功。所以不是 X 在某个时间统一打开或关闭了这个功能。

## 跟账号的什么有关？（还不知道）

| 猜测 | 支持 | 反对 |
|---|---|---|
| X 在做灰度测试，只给一部分账号开了 | 最能解释"同一个文件换账号就不行" | X 没有公开说过 |
| 会员等级（比如只有 Premium+） | — | 没法从外面查 |
| 地区 | — | 成功的有德语账号和中文账号，失败的也有中文和英文账号 |
| 是否认证（蓝标） | — | 成功和失败的账号几乎都有认证 |

想弄清楚，最直接的办法是：把**同一个测试文件**交给几个账号各发一次，看谁成功，再对比这些账号的会员等级和设置。

## 为什么不能把 HDR "固定"在画面里

视频里每个像素只是一个 0–255 的数字（8 位）。同一个数字 235：

- 按普通视频（BT.709）的规则播，就是界面白那么亮；
- 按 HLG 的规则播，手机会把它推到界面白的好几倍。

"按哪种规则播"写在色彩标记里。X 重新压缩以后，文件里写什么由 X 决定。我们的第 3 次测试里，X 原样保留了画面数字，但没写标记，手机就按普通视频播。普通视频最亮只能到界面白，超过界面白的"发光"做不出来。
